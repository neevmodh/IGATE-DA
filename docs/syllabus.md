# GATE DA (Data Science & Artificial Intelligence) Syllabus

Source: Official GATE syllabus (IISc/IIT-hosted, verified via GeeksforGeeks summary, Sept 2026). Re-verify each year against the official GATE portal (gate20XX.iitg.ac.in or hosting IIT) since the host institute rotates.

## Exam Pattern
| Aspect | Details |
|---|---|
| Duration | 3 hours |
| Mode | Online CBT |
| Total Marks | 100 |
| Total Questions | 65 |
| General Aptitude | 10 questions, 15 marks |
| Core Subject | 55 questions, 85 marks |
| Question Types | MCQ, MSQ, NAT |

**Marking:**
- General Aptitude: 5 × 1 mark + 5 × 2 marks
- Core Subject: 25 × 1 mark + 30 × 2 marks
- Negative marking (MCQ only): −1/3 for 1-mark, −2/3 for 2-mark
- No negative marking for MSQ or NAT

## Sections

### 1. Probability and Statistics
Counting, axioms of probability, conditional probability, Bayes' theorem, random variables, distributions (Uniform, Bernoulli, Binomial, Normal, t, Chi-squared), mean/median/mode, variance, correlation, hypothesis testing (z-test, t-test, Chi-squared test), confidence intervals.

### 2. Linear Algebra
Vector spaces, matrices, determinants, rank, systems of linear equations, eigenvalues/eigenvectors, matrix decomposition (LU, SVD), quadratic forms, projections.

### 3. Calculus and Optimization
Single/multi-variable functions, limits, continuity, differentiability, Taylor series, maxima/minima, gradient descent, constrained/unconstrained optimization.

### 4. Programming, Data Structures & Algorithms
Python programming, stacks, queues, linked lists, trees, hash tables, searching, sorting, divide-and-conquer, graph algorithms, time/space complexity.

### 5. Database Management & Warehousing
ER model, relational model, SQL, relational algebra, normalization (1NF–BCNF), indexing, data transformation, ETL, data warehousing (star/snowflake schema, OLAP).

### 6. Machine Learning
- Supervised learning: linear/logistic regression, decision trees, SVM, k-NN, ensemble methods (bagging, boosting, random forest)
- Unsupervised learning: k-means, hierarchical clustering, GMM
- Dimensionality reduction: PCA, LDA
- Neural networks: feedforward, backpropagation, CNN, RNN basics
- Model evaluation: bias-variance, cross-validation, precision/recall/F1, ROC-AUC, regularization (L1/L2)

### 7. Artificial Intelligence
Search techniques (BFS, DFS, A*, hill climbing), propositional and predicate logic, reasoning under uncertainty, Bayesian networks, Markov decision processes basics.

### General Aptitude
Verbal ability, quantitative aptitude, analytical reasoning.

## Weightage Notes (from past papers)
- Machine Learning and Probability/Statistics tend to carry the heaviest weight.
